## 5. 幂等与例外

- A6 首跑 changed≥1（base role 写入 sysctl/hosts 等，有实际变更）。
- A7 二跑 `changed=0`（幂等，所有 task 均 ok/skipped）。
- 受限：沙箱以 `ansible_connection=local` + 普通用户 become root 验证；`swapoff` / 改主机名等宿主级破坏性操作在契约 §7 中声明为受限，不在沙箱内执行（base role 在无 `become` 时会跳过宿主级任务，以变量 `base_swapoff_enabled=false` / `base_hostname_set=false` 保护）。

## 7. 风险与假设

- 沙箱 become 实测依赖宿主 NOPASSWD sudo（`sudo -n true`），若环境无此权限则 A6/A7 置 SKIP 并出具真机复验步骤。
