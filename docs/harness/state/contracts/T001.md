## 1. 目标（本任务交付什么）
建立 Ansible 项目骨架与开发入口：`ansible.cfg`、示例 inventory、`group_vars` 分层、`roles/` 约定、五个 playbook 入口占位、`Makefile`（help/syntax/yamllint/lint/test）、`.gitignore`（密钥防护）、`.yamllint`，以及本任务的测试脚本。

## 2. 非目标（明确不做什么）
- 不实现任何 role 的实际逻辑（T002+ 负责）。
- 不实现 group_vars 的最终变量集（仅给出分组骨架与必要占位）。
- 不安装/下载 k8s 二进制。

## 3. 依赖
- 依赖任务：无。
- 前置条件：`ansible-playbook`（ansible-core）可用；`yamllint` 可用。环境见 `standards/repo-conventions.md`。

## 4. 可验证验收项

| # | 验收项 | 验证方式 | 期望 | 判定 |
