## 5. 幂等与例外
- 幂等期望：沙箱内文件类任务连跑两次，第二次 `changed=0`。
- **受限声明（重要，对应 spec R1；r1 按实测更正）**：本环境 PID1 为 **systemd**
  （`systemctl is-system-running` 可运行）、**免密 sudo 可用**；但这是**共享开发机**，
  **禁止执行 `swapoff` / `sysctl --system` / 改主机名 / 改时区 / 启停服务等破坏性主机级变更**；
  同时**无可用容器、制品仓库不可达**，无法做多发行版真机验证。
  故以下“主机级效果”**无法在此真实验证**，仅做「接线断言 + 语法断言 + 跨发行版变量求值断言」：
  `modprobe` 实际加载、`sysctl --system` 生效、`swapoff -a` 运行时生效、`hostname`/`timedatectl` 实际变更、
  `chrony` 服务启用、firewalld/SELinux 实际状态。
  → 验证方式改为 **sandbox 前缀 + 真实执行文件类任务**（真实：模板渲染、落盘内容、文件权限、幂等），
  以 `--list-tasks --tags base:system` 证明系统级任务已接线，并用
  `tests/base/assert_ntp_service.yml` 覆盖 `chronyd`/`chrony` 服务名的发行版差异。
  **如需真机验证，须在具备 VM/隔离环境重跑。**
