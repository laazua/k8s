## 1. 目标（本任务交付什么）

1. **一条命令跑完整条生命周期**：`make test-e2e-full` → 干净 inventory → 集群可达 →
   调度约束 → 加节点 → 升级 → 回滚，全部由 `tests/e2e/full_flow.sh` **自己断言**
   （不调用其它测试脚本冒充复现），连跑两次逐条一致（归一化沙箱路径/PID）。
2. **同一轮内复现 T013/T014/T015 的验收关键断言**（各自验收摘要级，不是全量 711 条）。
3. **使用文档**：`docs/usage.md` + `docs/variables.md`（由 role defaults 生成的完整变量表）
   + 根 `README.md` 增加「部署快速开始」链接（不删改 harness 章节），覆盖前置条件、
   inventory、全部可配置项、代理/离线、部署、验证、调度约束、加节点、升级、回滚、已知限制。
4. **补齐缺口的真实部署编排**：`playbooks/control-plane.yml` / `playbooks/node.yml` 目前仍是
   `Placeholder - roles pending` 占位（T007/T008/T012 注释均承认「编排属 T012」但未落），
   `make deploy` 会空跑。本任务把它们改成真实 role 编排 + `make deploy` 一键入口。

### 3.2 设计取舍（请 Evaluator 重点判断）
1. **一个沙箱跑三段验收**：单 inventory（cp1/etcd1/node1/node2）+ 单 `$SB` 前缀，
   依次 taints（真实 CM/scheduler 调度判定）→ add-node（node2 真实 kubelet 注册）→
   upgrade/rollback（1.31.0 → 1.32.13 → 回滚）。只有这样才能证明「同一轮全流程」。
2. **生产入口编排**是 T016 的真实缺口：`playbooks/control-plane.yml`/`node.yml` 落地为 role
   编排，`make deploy` 指向 `playbooks/site.yml`。沙箱用 `tests/e2e/sandbox_*.yml` 走**同一批
   role/变量**（路径/端口/`manage_service` 重定向），并在静态段断言「真实入口 role 顺序」
   与沙箱编排顺序一致；生产多机 HA 仍属受限项（§5）。
3. **文档变量覆盖用生成物 + 双向校验**：`docs/variables.md` 由 `scripts/gen_vars_doc.py` 从
   `roles/*/defaults/main.yml` 生成（key/默认值/注释即「影响」），`full_flow.sh` 断言
   ①每个 defaults key 都出现在文档 ②重新生成后与提交内容一致（防文档漂移）。
4. **升级阶段停 CM/scheduler**：沙箱无 systemd，回滚要停 etcd/apiserver/kubelet 并恢复 etcd
   数据目录；为避免 CM/scheduler 持有失效 watch 干扰，升级阶段开始前停掉两者（T013 断言已
   在此之前完成，且升级不依赖它们）。真实生产由 systemd 控制，不需要该动作。
5. **重复输出归一化**：`full_flow.sh` 的 PASS/FAIL 标签不含 PID/临时路径；日志落
   `/tmp/opencode/t016_full_<run>.log`，两次 `diff` 只允许计时行。

## 7. 风险与假设

- **单宿主、无镜像、无 systemd 启停**：Pod 不 Running、多节点/多成员 etcd/VIP 未真机验证；
  该受限在 §5 与 `docs/usage.md`「已知限制」中显式声明，真机复验步骤见 usage。
- **沙箱与生产的差异必须显式补齐**：生产 worker 由 `roles/node.yml` 安装 `kube-proxy`，沙箱此前
  只装配 containerd/kubelet，导致升级备份组件清单 `kubelet,kube-proxy` 第二项缺失而中止（本轮根因）。
  沙箱补装 kube-proxy 只落二进制、不启动（无需 systemd），因此无进程/端口泄漏。
- **升级阶段停 CM/scheduler**（沙箱无 systemd 的取舍）：T013 断言已在此之前完成，升级不依赖它们。
- **宿主红线**：只写 `$SB`，不写 `/etc/kubernetes`、`/etc/systemd/system`；不 `systemctl`；
  停进程只按 `$SB/.../usr/local/bin/*` 精确匹配。`/tmp/opencode` 需 ≥6G（脚本前置守卫）。
- **成本**：`make test-e2e-full` 单跑约 25–40 分钟，双跑用于逐条一致性；全量 `make test`
  （约 85 分钟）不在本任务预算内，以 lint + 四个套件各一次替代，并在 §9.3 显式声明。
- **快照空端口是合法基线**：宿主初始无占用时 `ports=` 为空串，判定必须放行；`__ERROR__`/`__EMPTY__`
  仍判失败（否则采集故障被静默）。
