## 1. 目标（本任务交付什么）

关闭 T012 r1 的 MINOR/MAJOR 中由 Planner 指派给本任务的 7 项，且**不改变 sandbox 语义与计数**：

1. `--mode` / `--image` / `--kubeconfig` 缺值 → `rc=2` 立即退出，不再挂起（T012-D3）；
2. real 模式 API 不可达 / `kubectl` rc≠0 / 节点或 Pod 列表为空 → `FAIL`，禁止 `0/0` 空集恒真 PASS（T012-D1）；
3. `--image` Job 创建被拒 → `FAIL`（含 API 错误摘要），不得降级 `SKIP`（T012-D2）；
4. 清理失败影响最终 `RESULT`：`RESULT` 改到 cleanup 之后打印，每步清理失败记 `FAIL`（T012-D4）；
5. `--static-only --mode real` 不再强制 `--kubeconfig`（T012-D5）；
6. Service ClusterIP 与 CoreDNS 版本改为从 role defaults 读取（env 可覆盖并校验），消除双源（T012-D6）；
7. 契约套件断言 `SKIP` **恰好 3 条**且三条文案均匹配（T012-D9）；
8. 顺带按 T013/T014 做法修 `kubepods.slice` 清理粒度：只停本次新增 slice（T012-D7 的清理部分）。

## 2. 非目标（明确不做什么）

- 不实现 real 模式的跨节点 Pod 自动投放（需真实多节点拓扑，仍 `SKIP`）。
- 不改 sandbox 检查项/文案/计数（保持 30 PASS / 0 FAIL / 3 SKIP）。
- 不改 `spec.md` / `roadmap.md` 的验收定义；不触碰其它 role、playbook、Makefile。
- 不新增宿主依赖（仍只用 bash/python3/curl/systemctl/kubectl；无 jq）。
- 不修 T012-D8（静态检查粒度只查存在）——不在本任务范围。

## 3. 依赖、环境事实与设计取舍

- 依赖：T012 的 `smoke.sh` / `test_smoke_contract.sh` / README。
- 环境事实：本机无真实集群（`/etc/kubernetes` 不存在），real 模式只能以 stub kubectl 覆盖失败路径。
- 取舍：
  1. **用 stub `kubectl` 覆盖 real 失败路径**（`KUBECTL` env 指向临时 stub），
     不依赖真实集群、不联网、不落宿主；三种模式 `unreachable` / `empty-nodes` / `job-forbidden`。
  2. **解析用 `-o json` + python3**（一次查询同时得节点数与 Ready 数，避免两次 `get nodes`
     之间的状态漂移，且 rc 与「空集」可区分）。`--no-headers | wc -l` 无法区分失败与空。
  3. **CoreDNS 版本取自 `roles/cluster-addons/defaults/main.yml`**，但 sha256 无法从 role 推导，
     故保留 `CD_SHA_MAP` 显式登记；版本不在表内 → 显式 `FAIL`（拒绝静默下载未校验制品）。
     覆盖入口 `E2E_COREDNS_VERSION`。
  4. **Service IP 取自 `group_vars/all/main.yml` 的 `k8s_service_cidr`**（回落
     `roles/kube-apiserver/defaults`），用 `ipaddress` 校验首个 IP 落在 CIDR 内；
     `E2E_SERVICE_IP` 可覆盖但同样校验。不新增 PASS 行（保持 sandbox 计数 30）。
  5. **cleanup 失败语义**：`cleanup()` 幂等、每步失败调用 `bad "清理失败: ..."`，
     主流程在打印 `RESULT` **之前**显式调用并 `trap - EXIT`；`trap cleanup EXIT` 仅作异常兜底。
     `rm` 后校验目录已消失，`stop_proc` 校验进程已退出，`restore_kernel_tunables`
     回读 `/proc/sys` 校验，`kubepods` 只停前后差集新增项。
  6. kubectl 调用统一经 `k()`，带 `--request-timeout=15s`；错误信息带 rc 或 API stderr 摘要。
