- 位置：`tests/upgrade/test_upgrade_flow.sh:42-50`
- 复现：把 `ansible.cfg` 的 `stdout_callback` 换成非 default（如 `minimal`/yaml），`TASK [` 块结构消失 → `task_status` 恒空 → D2/A4 断言全红
