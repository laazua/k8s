## 6. 遗留缺陷（均非阻塞）

### [MINOR] D1 · D6 的静态断言是「文本存在」型，无牙齿
- 位置：`tests/add-node/test_add_node_flow.sh:431-432`（`grep -q 'add_node_verify_reason.stdout'`）
- 复现：把 `roles/add-node/tasks/verify.yml` 的 reason assert 改为 `when: false`，按断言形态套件仍会 276/0/2（未单独跑该变异）
- 期望：删/弱化该 assert 时套件变红
- 实际：仅校验字符串存在；真正载荷由「未注册节点 rc≠0」与测试侧读 `status.conditions` 兜底，因此风险有限
- 建议方向：改为用一个「Ready=False 且 reason 为空」的伪造节点对象跑 verify，断言 rc≠0（或以 schema 校验替代 grep）
