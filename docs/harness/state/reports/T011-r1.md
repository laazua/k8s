## 4. 缺陷清单

无 BLOCKER / MAJOR。

### [MINOR] D1 · role 自检与配置同源，缺少独立底线
- 位置：`roles/cluster-addons/tasks/verify.yml:10-18`
- 复现：worktree 内把 `cluster_addons_kubeconfig_mode` 改为 `"0644"` 后跑套件
- 期望：role 自身 verify 应拒绝非 0600
- 实际：verify 的断言是 `item.stat.mode == cluster_addons_kubeconfig_mode`，随变量一起漂移，
  role 自检仍通过；仅靠测试的硬编码 `600` 断言（4 项）变红
- 建议方向：verify 断言固定底线（例如断言 `item.stat.mode == "0600"`），
  或在 validate 里限制 `cluster_addons_kubeconfig_mode` 只能是 `0600`

### [MINOR] D2 · 清理断言恒真
- 位置：`tests/cluster-addons/test_cluster_addons_role.sh:353`
- 复现：`SB=""` 之后执行 `test ! -d "$SB"`
- 期望：断言原始沙箱路径已被删除
- 实际：`test ! -d ""` 永远为真，该断言无牙齿
- 建议方向：`rm -rf` 前保存 `SB_LAST="$SB"`，断言 `! -d "$SB_LAST"`

### [MINOR] D3 · fail-fast 的「不落盘」断言覆盖不全
- 位置：`tests/cluster-addons/test_cluster_addons_role.sh:217`
- 复现：把 validate 挪到 manifests 之后（模拟回归）
- 期望：任何一项产物都不落盘
- 实际：只断言 `coredns.yaml` 不存在；`rbac.yaml`/kubeconfig 可能已写入而漏检
- 建议方向：断言整个 `addons/manifests` 目录不存在，或断言 `rbac.yaml` 亦不存在

### [MINOR] D4 · 契约引用未创建的真机 playbook
- 位置：`docs/harness/state/contracts/T011.md` §5.6
- 实际：`tests/cluster-addons/real_addons.yml` 不存在（契约已在注中说明）
- 建议方向：真机任务（T012/T016）补齐，或 §5.6 改为纯手工 `kubectl apply` 步骤
